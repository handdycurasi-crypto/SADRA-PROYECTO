AVANCE 01 - PROYECTO SADRA

Nombre del proyecto:
SADRA: Sistema de Análisis y Detección de Riesgo en Anuncios Digitales mediante OCR y Clasificación de Texto.

Descripción:
Este proyecto analiza anuncios digitales sospechosos de redes sociales. El sistema recibirá una imagen y una descripción del anuncio. En esta primera versión se implementa una clasificación básica por reglas usando C++.

Estado del avance:
- Se elaboró el informe del avance 01.
- Se definió la arquitectura inicial del sistema.
- Se crearon las clases principales en C++.
- Se implementó una clasificación básica por reglas.
- Se agregó una estructura inicial para el módulo Python.
- La integración completa con Python, OCR y Scikit-learn queda para el siguiente avance.

Tecnologías:
- C++
- Python
- OCR
- Scikit-learn
- NLTK o spaCy

Temas de POO aplicados:
- Clases y objetos
- Encapsulamiento
- Constructores
- Composición
- Herencia
- Polimorfismo
- Clase abstracta
- Manejo de archivos

Próximos pasos:
- Conectar C++ con Python.
- Integrar OCR para extraer texto desde imágenes.
- Mejorar la clasificación con Scikit-learn.
- Crear diagramas UML.
